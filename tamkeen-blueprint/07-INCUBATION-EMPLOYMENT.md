# 07 — الحاضنة والتدريب وفرص العمل

## مثال حاكم: مشروع زراعي

صاحب فكرة يقترح وحدة زراعة؛ جهة مشغلة تتبنى التنفيذ؛ جهة راعية تمول تجهيزًا وتدريبًا ومنح حضور؛ شباب يتقدمون؛ دفعة تتدرب عمليًا؛ الشركة تعرض وظائف متاحة وفق معايير معلنة؛ من لم يتوظف يحصل على نتيجة صادقة وخطة متابعة. المشروع يجمع أثرًا اجتماعيًا ونشاطًا اقتصاديًا، لكن التمويل المقيد لا يتحول تلقائيًا إلى أسهم للشركة.

## الفصل البنيوي

EnablementProject: الهدف والمسؤوليات. Program: التدريب والخطة. Cohort: مجموعة ومواعيد وسعة. FundingAgreement: المال ومصدره واستخدامه. Job: وظيفة فعلية. Application: ترشح. Enrollment: قبول والتحاق. Placement: توظيف موثق. VentureProposal: فكرة شاب قابلة للاحتضان. الشاب قد يكون صاحب فكرة ومتدربًا وباحثًا عن عمل في الوقت نفسه.

## مخطط التمويل

راعٍ/منحة/تبرع مقيد → وعاء البرنامج → ميزانية تجهيز وتدريب وبدلات → طلب صرف لكل بند → اعتماد مستقل → تسوية → إثبات حضور/توريد → مراجعة أثر. إن وجد استثمار في الشركة فهو Offering مرتبط آخر، ولا تُصرف تبرعات التدريب لتوزيع أرباح.

## آلة الحالات

Program: draft → review → approved → recruiting → selection → active → completed → follow_up → closed، مع paused/cancelled.

Application: draft → submitted → screening → shortlisted → interview → accepted/waitlisted/rejected → withdrawn. قبول الطلب ينشئ invitation؛ Enrollment يصبح confirmed بعد قبول الشاب خلال المهلة. انتهاء المهلة يحرر المقعد ويستدعي التالي من قائمة انتظار موثقة.

Enrollment: invited → confirmed → active → completed / dropped_out / terminated. Job application لها آلة مستقلة ولا يعتبر قبول التدريب قبول وظيفة.

Placement: offered → accepted → start_pending → started → verified_30d → verified_90d → retained / ended / disputed. مقابلة أو عرض دون بدء ليس توظيفًا محققًا.

## إعداد البرنامج

حقول إلزامية: اسم، جهة راعية ومشغلة، مسؤول، موقع فعلي/عن بعد، موضوع ومهارات، مستوى، شروط عمر/تعليم حيث مبررة، سعة، نافذة تقديم، مدة وساعات، جدول، سياسة الحضور، آلية تقييم، بدل وقيمته وشروطه، ميزانية، عدد وظائف متوقعة أو ملزمة ووثيقة الالتزام، طريقة المفاضلة، ترتيبات الإتاحة، خصوصية، سياسة انسحاب، مسؤول الشكاوى.

لا تَعِد جميع المتقدمين بوظيفة. إذا أعلن «10 وظائف» يظهر هل هي مستهدفة أم عروض ملتزمة وما معاييرها ومتى تتاح. لا يطلب المسمى الوظيفي أو الفرصة رسوم تقديم غير موثقة.

## التقديم والاختيار

ملف مهارات وخبرات + أسئلة برنامج محددة + مستندات لازمة فقط → حفظ مسودة → إرسال → تأكيد رقم الطلب → فرز قواعد معلنة → تقييم بشري → مقابلة → قبول/انتظار/رفض مع سبب مناسب → قبول المقعد. منع طلب مكرر لنفس cohort، وسعة قبول محمية بقفل/معاملة عند التزامن.

## التشغيل اليومي

المدرب يرى دفعاته فقط، يسجل جلسة وحضورًا أو غيابًا بعذر وتقييمًا مبنيًا على rubric. تعديل حضور قديم يحتاج سببًا ويسجل revision. الشاب يرى سجله ويعترض. إذا ارتبط بدل بالحضور، لا يُصرف قبل تثبيت الفترة وحسم الاعتراضات المتعلقة بالاستحقاق. التدريب العملي يحتاج جهة ومشرفًا ومسؤولية واضحة.

الشهادة تصدر عند تحقق متطلبات البرنامج بمرجع تحقق عام محدود، لا تحتوي هوية وطنية. سحب شهادة يصير revoked مع سبب خاص وإظهار أن المرجع غير صالح.

## التوظيف والمتابعة

الشركة تنشر وظيفة مرتبطة أو مستقلة بتفاصيل أجر/نطاق إن أتيح، نوع عقد، موقع، ساعات ومتطلبات. ترشيح متدرب يحتاج موافقته على مشاركة ملفه. Recruiter يدير shortlist/interview/offer. عرض versioned يقبله الشاب أو يرفضه؛ قبوله لا يثبت بدء العمل. يجمع بدء العمل من الطرفين أو دليل يراجعه مسؤول مخول؛ تنشأ متابعة بعد 30 و90 يومًا من تاريخ البدء الفعلي، لا من تاريخ إنشاء الطلب.

متابعة: يعمل/انتهى/غير معروف/متنازع، تاريخ، سبب، دليل، من أكد. عدم الرد = unknown وليس نجاحًا. تسجل وظيفة مستقلة وجدها الشاب خلال المتابعة مع درجة تحقق ومصدر، وتفصل عن التوظيف المباشر عبر البرنامج.

## احتضان فكرة شاب

اقتراح خاص → فحص ملاءمة → مقابلة → قبول احتضان → اتفاق أهداف ومنحة وملكية فكرية ومسؤوليات → تعيين mentor → milestones ونموذج أولي → تحقق → انتقال إلى إنشاء Startup أو وظيفة أو إنهاء مسبب. لا تأخذ المنصة أسهمًا افتراضيًا مقابل التقديم. أي حصة لحاضنة تتطلب اتفاقًا صريحًا ومسار استثمار مستقل.

## الإغلاق

تسوية الميزانية والمصروفات والبدلات، أرقام المقبولين والمنسحبين والمكملين والموظفين والاحتفاظ، نتائج مجهولة، رد فائض وفق اتفاق التمويل، مراجعة راعٍ، تقرير عام منقح، وإشعار المشاركين. الإلغاء أثناء التدريب يحتاج خطة للمقاعد والبدلات المستحقة والمعدات والسجلات والوظائف المرتبطة.
