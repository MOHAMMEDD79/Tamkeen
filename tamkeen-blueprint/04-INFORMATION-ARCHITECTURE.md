# 04 — خريطة المعلومات ولوحات الأدوار

## التنقل العام

الرئيسية، استكشف، الخريطة، المؤسسات، الاستثمار، التدريب والعمل، الأثر، عن تمكين. ابحث باستخدام query محفوظة في URL؛ back يعيد الفلاتر والتمرير. اللغة جزء من المسار `/{locale}`. مسارات `screens` تختصر بادئة اللغة.

## Personal workspace

`/app`: نظرة عامة شخصية، مساهماتي، استثماراتي، طلباتي، تدريبي، فرصي الوظيفية، مساعداتي، تطوعي، محفوظاتي، الإشعارات، الإعدادات. تظهر الأقسام حسب القدرات ويستطيع المستخدم تفعيل قدرة جديدة من الإعدادات؛ تبقى الالتزامات القديمة قابلة للوصول عند تعطيل عرض القدرة.

| لوحة | ما يراه صاحبها أولًا | مهامه | غير معروض |
|---|---|---|---|
| Donor | إجمالي مدفوع/مسترد، تحديثات مشاريعه | مساهمة، إيصال، متابعة، خصوصية، طلب استرداد | دفتر المؤسسة الكامل |
| Beneficiary | حالة طلبه والخطوة التالية | تقديم أدلة، الرد، قبول دعم، شكوى | أسماء بقية المستفيدين |
| JobSeeker | طلبات ومواعيد وتدريب وعروض | إكمال مهارات، التقديم، حضور، قبول عرض | ملاحظات التقييم الداخلية |
| Investor | ملتزم/مسوى/مخصص، مستندات وتحديثات | أهلية، فحص عرض، اكتتاب، تقارير | اعتباره مالكًا قبل التخصيص |
| Volunteer | فرص وطلبات ومهام وساعات معتمدة | تقديم، قبول مهمة، تسجيل ساعات | ملفات مستفيدين إلا تكليف مصرح |

## Organization workspace

`/org/:orgId`: اسم الجهة ونوعها وحالة التوثيق والسياق ظاهر دائمًا. أقسام مشتركة: نظرة عامة، الفريق، التوثيق، الملف العام، الوثائق، الإشعارات والإعدادات. أقسام إضافية حسب capabilities:

- Charity: المشاريع، المساهمات، الميزانيات، طلبات الصرف، التقارير، طلبات المساعدة، التطوع.
- Company / Startup: المشاريع التجارية، عروض الاستثمار، غرفة البيانات، المستثمرون والتخصيص، التقارير، برامج التدريب، الوظائف، الشراكات.
- Program operator: البرامج، الطلبات، الدفعات، الحضور، التقييم، المصروفات، الوظائف، التوظيف والمتابعة.
- Foundation / Government sponsor: محفظة تمويل، منح واتفاقات، مراحل صرف، أثر مجمع، تقارير. يمكن تفعيل التشغيل إذا كان مصرحًا للجهة.

الجهة قد تجمع أكثر من مساحة دون إنشاء حساب آخر. يُمنع عرض قسم لا تسمح به capabilities؛ الرابط المباشر يتحقق أيضًا بالخادم.

## Admin workspace

`/admin`: قوائم العمل حسب اختصاص الموظف: توثيق جهات، مراجعة مشاريع/عروض، مراقبة المدفوعات والتسوية، مراجعة نزاعات، تجميد وفك تجميد، تقارير شفافية، إدارة صلاحيات تشغيل، audit. لا تُنشأ لوحة «مدير يرى الجميع» كحل افتراضي.

## قواعد العلاقات

- صفحة مؤسسة ← مشاريعها ← مشروع ← الجهة المسؤولة؛ لا روابط ميتة.
- إيصال ← المساهمة ← المشروع ← التقرير؛ لا كشف هوية عامة في هذه السلسلة.
- التزام ← العرض ونسخة إفصاحه ← الشركة ← التخصيص المثبت.
- طلب تدريب ← البرنامج ← الجهة ← التدريب ← الوظيفة ← التوظيف ← متابعة 30/90 يومًا.
- بطاقة خريطة تفتح صفحة عامة فقط. الإحداثيات الدقيقة للمستفيد لا تدخل index العام.
- breadcrumb لا يكشف اسم كائن خاص لمستخدم غير مخول.

## حالات التنقل

غير مسجل: يعاد إلى تسجيل الدخول مع returnTo داخلي آمن. غير مخول: forbidden أو not found حسب حساسية الكائن. توثيق منتهي: صفحة قراءة مع دعوة تحديث التوثيق ومنع العمليات المقيّدة. جهة معلقة: بيان واضح وحدود الصرف/النشر، مع إبقاء الشكاوى والسجلات متاحة لأصحابها.
