# 13 — الإشعارات وعمليات التشغيل

## سياسة التسليم

الإشعار نتيجة حدث domain محفوظ بـoutbox. داخل المنصة أساسًا، بريد للمعاملات والمواعيد حسب preference، SMS لاحقًا. Dedup key = event + recipient + template version. فشل إرسال لا يعكس نجاح مال أو قبول؛ retries مع backoff ثم dead-letter قائمة مراجعة.

| الحدث | المستلم | الرسالة/الرابط | مهلة تشغيل مقترحة وليست وعد SLA نهائيًا |
|---|---|---|---|
| توثيق أرسل/طلب تعديل | مراجع/مسؤول جهة | رقم حالة ونواقص → التوثيق | مراجعة خلال يومي عمل تجريبيًا |
| دفع تأكد/استرداد تأكد | صاحب المساهمة | مبلغ ومرجع → تفاصيل خاصة | فوري عبر outbox |
| مشروع حدث/اكتمل | المتابعون | عنوان تحديث عام → التقرير | حسب تفضيل المتابعة |
| طلب صرف | معتمدون مستقلون | وعاء ومبلغ → مراجعة صرف | تنبيه بعد يوم عمل |
| فرق تسوية | FinanceOperator | مرجع دون بيانات بطاقة → reconciliation | قائمة عمل يومية |
| أهلية استثمار أو تغير إفصاح | المستثمر المعني | إجراء مطلوب → العرض/الأهلية | قبل السماح بمتابعة اكتتاب |
| تخصيص/توزيع | المستثمر | حالة مؤكدة → المحفظة/المستند | بعد الإثبات فقط |
| دعوة مقابلة/قبول مقعد | المرشح | موعد/مهلة → طلبه | تذكير قبل انتهاء المهلة |
| جلسة تدريب | المسجلون | زمن ومكان مسموح → جدولي | قابل للضبط، مع timezone |
| عرض عمل | المرشح | إشعار خاص → العرض | مع مهلة صلاحية |
| متابعة 30/90 | المرشح والمشغل | استبيان قصير → placement | من بدء العمل الفعلي |
| شكوى أو نزاع | مقدم الشكوى/المسؤول | رقم حالة → تذكرة | تصعيد حسب الأولوية |

## التذاكر والنزاعات

ticket: open → assigned → awaiting_user / awaiting_internal → resolved → closed؛ reopen ضمن السياسة. موضوعات: دفع، هوية، محتوى، تدريب، توظيف، وصول. كل تذكرة owner وpriority وnext_action_at. إغلاق يحتاج resolution code وشرح. شكوى مالية تنشئ dispute مرتبطًا عند الحاجة، لا تستبدل ledger event.

## قوائم الإدارة

قوائم منفصلة للتوثيق، النشر، أهلية الاستثمار، تقارير الأثر، الصرف، التسوية، البلاغات. يدعم claim/reassign لمنع مراجعين يعملان قرارين متعارضين؛ version عند القرار. المراجع يرى أدلة وhistory وسبب القرار، والأزرار approve/request_changes/reject تظهر حسب حالة وصلاحية.

## أدلة تشغيل قصيرة

- webhook توقف: راجع health/inbox/last_event؛ أعد جلب حالة المزود؛ replay لنفس event_id؛ لا تنشئ دفعًا بديلًا.
- payout unknown: أوقف retry المالي، استعلم مرجعيًا، أثبت paid/failed، حرر حجزًا فقط عند الفشل المؤكد.
- تسرب بيانات محتمل: قيد الوصول المتأثر، احتفظ بالآثار، بدّل أسرارًا متأثرة، حدد نطاقًا، سجل incident ومسؤول المتابعة.
- برنامج ألغي: وقف تقديم وقبول، جرد حقوق متدربين وبدلات، نشر تعليمات، خطة إغلاق تمويل، مراجعة أثر.
- موظف غادر: ألغ عضويته والجلسات والروابط حسب السياسة، أعد إسناد مشاريعه وطلباته، لا تحذف تاريخ قراراته.
