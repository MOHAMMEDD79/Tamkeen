# 21 — النماذج والحقول

## قواعد مشتركة

trim ونص Unicode آمن مع الحفاظ على العربية؛ أطوال معلنة؛ server validation مطابق أو أشد؛ تواريخ بداية قبل نهاية؛ أرقام نقدية صحيحة موجبة وفق currency exponent؛ URL protocols allowlist؛ لا HTML خام. required حقليًا؛ لا تعتمد placeholder عنوانًا. تغيير سياق أثناء draft يطلب حفظ/تجاهل ولا ينقل المسودة لجهة أخرى تلقائيًا.

| النموذج | الحقول الإلزامية | اختياري/خاص | قواعد إضافية |
|---|---|---|---|
| فرد | اسم عرض 2–100، بريد، auth credential، موافقة شروط بنسخة | لغة ومدينة وصورة | تحقق بريد، لا إنشاء خمس هويات للأدوار |
| جهة | اسم قانوني، اسم عام، نوع، بلد، مدينة، مفوض | وصف/موقع/قطاعات/شعار | slug فريد؛ المستندات في التوثيق |
| دعوة | بريد، أدوار ضمن قدرة الداعي | رسالة قصيرة | expiry أحادي الاستخدام؛ لا دعوة owner ضمنيًا |
| توثيق | رقم تسجيل، جهة إصدار، وثائق ومفوض | صلاحية وثيقة وعنوان | نسخ، فحص ملفات، لا نشر وثائق الخام |
| مشروع | اسم 5–140، وصف ملخص 30–300، نوع، جهة، مسؤول، مدينة، مراحل | قصة وصور وموقع عام | ثبات النوع بعد النشر، موافقة صور |
| حملة | هدف/عملة/سياسة/مدة/ميزانية | فئات دعم/جهات شريكة | مجموع بنود الميزانية متسق وسبب أي فرق |
| مساهمة | مبلغ، payer context، سياسة، privacy choice | إهداء مؤجل | min/max من إعداد campaign؛ رسوم موضحة قبل التأكيد |
| صرف | pool، milestone/budget line، مستفيد، مبلغ/عملة، فاتورة، سبب | مذكرة | لا تجاوز المتاح، approver مختلف، snapshot بنك |
| استرداد | contribution/intent، مبلغ، سبب | مستند | remaining refundable مع حجز التزامن |
| عرض استثمار | مصدر، أداة، سعر، وحدات، min/max، مدة، استخدام مال، إفصاح | تقرير تقييم | min<=max؛ مجموع وحدات×سعر؛ eligibility policy |
| التزام | offering/version، مبلغ/وحدات، party، إقرار مخاطر/شروط | أسئلة قبل الالتزام | الكل يشتق ويؤكد بالخادم؛ لا وحدات كسرية |
| برنامج | مشغل/راعٍ، مهارات، سعة، مدة، جدول، أهلية، ميزانية، معايير قبول | بدل/وظائف متوقعة/إتاحة | فصل المتوقع عن الملزم وإظهار سياسة الانسحاب |
| طلب | target، ملف مهارات، إجابات مطلوبة، موافقة مشاركة | سيرة ومرفق لازم | unique user/target؛ حفظ draft؛ شرط deadline بالخادم |
| تقييم | rubric version، معيار ودرجة، ملاحظة | توصية | مجموع ضمن scale؛ لا كشف ملاحظة داخلية للمرشح |
| حضور | session، enrollment، status، recorder | عذر/دليل | المجموعة المسندة فقط؛ revision بعد الإقفال |
| وظيفة | جهة، مسمى، وصف، نوع عقد، موقع، مهارات، deadline | أجر/نطاق/ارتباط برنامج | لا وظيفة مجهولة الجهة؛ شروط عادلة موثقة |
| عرض عمل | مرشح، وظيفة، نسخة شروط، بدء، مدة قبول، مستند | مزايا | قبول النسخة الحالية فقط؛ توثيق انتهاء |
| متابعة | placement، checkpoint، نتيجة، تاريخ تحقق، مصدر | دليل وسبب انتهاء | لا تاريخ قبل بدء؛ unknown خيار صريح |
| فكرة | مشكلة، حل، مستفيد/عميل، مهارات صاحبها، احتياج احتضان | ميزانية أولية/ملفات | خاصة افتراضيًا وملكية فكرية واضحة |
| طلب مساعدة | نوع احتياج، وصف خاص، مدينة، consent لجهة | مستندات حسب النوع | لا تطلب صحة/بنك غير لازم؛ أقل وصول ممكن |
| تقرير | فترة، أنشطة، مصروفات مرجعية، نتائج، أدلة، مسؤول | قصة منقحة | الأرقام من النظام؛ فروقات تفسر ولا تحرر أرقام المال |

## المستندات

حدود أولية: صورة 10MB، PDF 20MB، عدد أقصى configurable حسب النموذج. تحقق magic bytes لا extension فقط؛ منع executables وHTML؛ quarantine أولًا. إزالة مستند مستخدم في عقد موقع أو اعتماد لا تمحوه: revoke access أو revision، مع حفظ النسخة المرجعية.

## صفحة checkout

ترتيب: السياق الدافع → المشروع/الجهة → مبلغ وعملة → رسوم ومخصص للمشروع → الخصوصية → سياسة الهدف والاسترداد → تأكيد → تحويل مزود. زر متابعة disabled عند خطأ مبلغ/سياسة غير مقرّة/جهة لا تقبل جمعًا؛ يشرح السبب نصيًا.
