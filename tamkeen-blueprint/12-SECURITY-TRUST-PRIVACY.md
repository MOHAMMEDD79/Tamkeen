# 12 — الأمن والثقة والخصوصية

## تصنيف البيانات

Public: مشروع منشور وتقرير منقح. AccountPrivate: مساهمات الفرد وطلباته. OrganizationConfidential: ميزانيات داخلية وعقود. HighlySensitive: هوية وأهلية وبنك وصحة. كل document له classification ومنح وصول؛ لا public bucket موحد.

## التوثيق

الجمعية: اسم قانوني، معرف تسجيل، جهة إصدار، مسؤول مفوض، إثبات عنوان/بنك عند التشغيل المالي. الشركة: بيانات كيان ومفوض وإفصاحات العرض المطلوبة. المتدرب: أقل معلومات لازمة للتقديم؛ لا طلب هوية حكومية لكل زائر. صلاحية الوثائق لها expiry ومراجعة بشرية؛ شارة «موثقة» تربط بحدود ما تحقق وتاريخه، ولا تعني ضمان نجاح.

## ضوابط تطبيقية

TLS بالإنتاج، secrets خارج git، session rotation، logout/revoke، حماية brute force، تحقق بريد، MFA للمراجعين والمال والملكية، CSRF، input validation، HTML sanitization، CSP، حماية SSRF للروابط المستوردة، حدود حجم upload وفحص malware والحجر قبل العرض. لا تنفيذ ملفات مرفوعة ولا تضمين HTML مستند غير موثوق داخل origin التطبيق.

أحداث حساسة: تغيير بنك، نقل ملكية، رفع صلاحية، تنزيل وثيقة هوية، اعتماد صرف، تخصيص، تجميد. تسجل actor, represented_party, resource, action, time, requestId, reason وحقول تغيرت منقحة. لا passwords/tokens/full payment payloads في logs.

## الخصوصية العملية

- هوية المتبرع العامة opt-in؛ صور المستفيدين وقصصهم بموافقة منفصلة قابلة للسحب.
- موقع مشروع عام بدرجة دقة مناسبة؛ عنوان منزل مستفيد لا ينشر.
- عدم نشر أسماء متدربين أو أصحاب طلبات مساعدة في التقارير؛ المجاميع الصغيرة قد تعيد التعرف على أشخاص، فتُخفف/تُحجب.
- الموظف يرى بيانات بحسب حاجته وتكليفه؛ support لا ينتحل المستخدم افتراضيًا. وصول طارئ مؤقت مع سبب ومراجعة وسجل ظاهر داخليًا.
- طلب وصول/تصحيح/حذف يمر تذكرة هوية مناسبة، يفرق بيانات يمكن حذفها من سجلات يلزم الاحتفاظ بها وفق سياسة التشغيل.
- analytics بلا بريد أو أسماء أو نص مستندات؛ روابط push/email لا تحمل تفاصيل صحية أو بنك.

## الثقة ومكافحة الإساءة

تكرار مشروع محتمل يولد قائمة مراجعة، لا رفضًا آليًا. بلاغ مشروع ينشئ تذكرة مع evidence؛ تجميد جمع وصرف حسب النطاق، مع سجل وقرار قابل للمراجعة. لا تستخدم score غير مفسر لترتيب الأشد حاجة أو توصية استثمار. تقييم الجهة في الإصدار الأول مؤشرات موثقة وتواريخ؛ reviews ونجوم لاحقًا بسياسة مستقلة.

## حدود الإطلاق

البلد والمشغل ومزود الأموال وأداة الاستثمار غير محسومة في المدخلات. يسجل مسؤول المنتج قرار تشغيل مع مراجعة مختص مناسبة قبل money_enabled؛ هذا لا يمنع العمل المحلي. لا تفترض لوائح أو مدة احتفاظ أو إعفاء ضريبي أو ترخيص. إيصال محلي «إيصال مساهمة» لا «شهادة خصم ضريبي» افتراضيًا.
