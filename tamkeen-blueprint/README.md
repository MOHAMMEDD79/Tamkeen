# تمكين — حزمة التخطيط والتنفيذ المحلي

نسخة التخطيط: 1.0 — 2026-09-15. اللغة الأساسية عربية RTL، مع دعم الإنجليزية LTR منذ الأساس.

هذه حزمة مواصفات وبرومبتات تنفيذ، وليست تطبيقًا منفذًا. كل ملف يحدد قرارات قابلة للتحويل إلى كود واختبارات. اكتمال التخطيط لا يعني أن التشغيل المالي الحقيقي معتمد أو أن تكاملًا خارجيًا يعمل.

## ابدأ هنا

1. افتح مجلد Tamkeen في Codex محليًا.
2. اقرأ [برومبت القيادة](00-MASTER-PROMPT.md) ثم [قرارات النطاق](01-PRODUCT-SCOPE.md).
3. استخدم [خطة المراحل](19-IMPLEMENTATION-ROADMAP.md)، وابدأ بـ [PART-01](parts/PART-01.md).
4. في كل جلسة الصق: «اقرأ tamkeen-blueprint/00-MASTER-PROMPT.md ونفّذ tamkeen-blueprint/parts/PART-XX.md فقط، ثم حدّث PROGRESS.md وTRACEABILITY.md بالأدلة الفعلية».
5. لا تطلب تنفيذ الملفات كلها في جلسة واحدة. كل مرحلة تنتج شريحة عاملة من قاعدة البيانات حتى واجهة المستخدم.

## حجم الحزمة وكيفية تعديلها

تتضمن 14 برومبت مرحلة، و87 مواصفة صفحة ومجموعة مسارات، و347 إجراءً خاصًا، إضافة إلى 19 إجراءً عامًا موروثًا. بعض المواصفات تجمع شاشة قائمة وتفاصيلها أو إنشاء وتحرير؛ لا يعني العدد 87 ملف واجهة مستقلًا بالضرورة.

المحتوى التنفيذي كله في ملفات Markdown. الملف `build-catalog.ps1` أداة صيانة محلية تولّد سجلات الشاشات وأجزاء التنفيذ؛ لا يبني التطبيق ولا يتصل بخدمات خارجية. إذا عدّلت الشاشات أو الأجزاء المولدة مباشرة، لا تعِد تشغيله قبل نقل تعديلاتك إلى مصدره لأنه يستبدل الملفات المولدة. بقية المواصفات مستقلة عنه.

اقرأ أيضًا [ضبط المسارات والإجراءات](screens/09-ROUTE-AND-ACTION-RESOLUTION.md) و[امتدادات الصلاحيات](screens/08-PERMISSION-EXTENSIONS.md)، خصوصًا للمستثمر المؤسسي والمهام وشاشات التحقق المساعدة.

## ترتيب مرجعية القرارات

طلب المستخدم الصريح ← قرار موثق أحدث في سجل القرارات ← قواعد المال والخصوصية والصلاحيات ← مواصفات المسار ← سجل الصفحات ← مثال بصري. عند التعارض أصلح المواصفة قبل التنفيذ ولا تخمن حركة أموال أو صلاحية جديدة.

## تعريف الاكتمال

كل زر له معرف، مالك، إذن، شروط تشغيل، أثر واضح، endpoint أو انتقال محلي، وحالة فشل قابلة للاستعادة. كل مبلغ له مصدر وقيد وتسوية. كل مستفيد أو متدرب له نتيجة قابلة للتحقق. كل مرحلة لها دليل تشغيل واختبار، وأي عنصر غير منفذ يبقى معلنًا كغير منفذ.
