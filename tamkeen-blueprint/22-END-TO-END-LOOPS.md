# 22 — إغلاق الحلقات والتتبع

## LOOP-CH — العمل الخيري

```text
ORG verification → project draft → review → publish → public detail
→ contribution checkout → provider callback pending → verified webhook
→ ledger + receipt → settlement → available budget
→ payout request → independent approval → provider paid
→ milestone evidence → reviewed impact → closing reconciliation
→ public final report → donor notification → archived read access
```

المالك: مدير الجمعية؛ المال: Finance؛ النتيجة: مراجع أثر. مخرج فشل التمويل: خطة refund ثم تسوية وإغلاق؛ مخرج صرف جزئي: التزامات متبقية وفائض/عجز معلنان. قبول الحلقة CH-01 + FIN-01..06 + PRIV-01.

## LOOP-INV — الاستثمار

```text
Issuer verified → venture → offering/disclosure → due diligence → open
→ investor eligibility → dataroom → version acceptance → commitment
→ subscription confirmation → payment settlement → closing capacity checks
→ allocation proof → holding → company reports → distribution/event
→ paid proceeds or documented loss/exit → final statement
```

المالك: مدير العرض؛ الموافقة: المراجع المخول؛ المال: Finance؛ الملكية: Allocation adapter. لا وصول من commitment مباشرة holding. فشل minimum: رد أموال وحل التزامات قبل الإغلاق. قبول INV-01..04 + FIN.

## LOOP-EMP — التدريب إلى العمل

```text
Idea/program → sponsor agreement + restricted pool → operator verified
→ program recruitment → application → selection → seat acceptance
→ enrollment → sessions/attendance/assessment → completion
→ stipend approval/payment + certificate
→ job application → interview → offer → candidate acceptance
→ actual start confirmation → day30/day90 followup → retained/ended/unknown
→ sponsor financial and outcome report → close
```

المالك: ProgramManager؛ التدريب: Trainer؛ الوظيفة: Recruiter؛ تأكيد النتيجة: أطراف ودليل؛ التمويل: Finance. عدم وجود وظيفة مسار نتيجة مشروع وشفاف مع توجيه لاحق، لا نجاح مزيف. قبول PRG-01..03 + JOB-01..02.

## LOOP-INC — فكرة إلى شركة

فكرة خاصة → قرار احتضان → اتفاق ومنحة منفصلة → mentor ومراحل → نموذج أولي متحقق → تأسيس جهة بواسطة الفرد → venture مرتبط → offering جديد إن طلب تمويل أسهم. لا تحويل صاحبه تلقائيًا إلى حساب مستخدم جديد، ولا نقل منحة إلى رأس مال مسجل بلا أساس.

## تعريف إغلاق موحد

لا طلب معلق بلا مالك؛ لا دفعة unknown مهملة؛ لا رصيد غير مفسر؛ لا عقد بلا نسخة؛ لا نتيجة بلا مصدر؛ لا إشعار قبل الحدث؛ وصول قرائي للسجل بعد إغلاق المشروع؛ حق تذكرة للمتأثرين. المهام المتأخرة تظهر في لوحة المسؤول مع موعد وإجراء تصعيد.
