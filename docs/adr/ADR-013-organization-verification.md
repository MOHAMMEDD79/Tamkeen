# ADR-013 — سجل توثيق الجهة

الحالة: مطبق محليًا كأساس ORG-04 ضمن PART-02.

## القرار

- تفصل مسودة التوثيق عن التسليم. يمكن تعديل المسودة فقط في `not_started` أو `changes_requested` وبـoptimistic version.
- لا يقبل التقديم إلا بيانات مكتملة، وتاريخ انتهاء مستقبلي عند وجوده، ووثيقة واحدة على الأقل، وكل الوثائق بحالة `clean` صادرة عن مسار الفحص.
- يقفل التقديم صف الجهة داخل معاملة، وينشئ snapshot غير قابل للتعديل يتضمن البيانات ومعرفات الوثائق، ويربط كل إعادة تقديم بالنسخة السابقة.
- يمنع SQL تعديل أو حذف التسليمات والقرارات. تعرض واجهة الجهة سبب القرار العام والنتيجة والتاريخ وتسلسل التسليم فقط؛ لا تعرض هوية المراجع أو storage keys أو checksums.
- تصنيف وثائق التوثيق ثابت `HighlySensitive`، والبصمة SHA-256 lowercase بطول 64 محرفًا بقيود قاعدة البيانات.
- في demo/test ينشئ الخادم upload intent مدته 15 دقيقة، ويخزن SHA-256 للرمز، ويلزم الحجم الدقيق ونوعًا من PDF/PNG/JPEG. يكتب الملف أولًا في quarantine، ويتحقق من magic bytes، ويرفض توقيع EICAR ومحتوى PDF النشط والـHTML، ثم ينقل الملف المقبول إلى clean ويبطل الرمز ذريًا في قاعدة البيانات.

## الحد الحالي

الفاحص الحالي دفاع محلي محافظ وليس بديلًا عن محرك malware محدث. التخزين المحلي محظور خارج demo/test؛ يلزم S3-compatible quarantine ومحرك فحص خارجي قبل الإنتاج. مسار المراجع الإداري الذي ينشئ القرار ويغيّر حالة القضية لم ينفذ بعد.
