# ADR-014 — أصول الجهة العامة

الحالة: مطبق محليًا للشعار ضمن PART-02.

## القرار

- شعار الجهة أصل `Public` مستقل عن وثائق التوثيق `HighlySensitive`، ولا يعاد استخدام جدولها أو مسار تخزينها.
- الرفع يمر عبر intent أحادي الاستخدام محدود بـ15 دقيقة وبـoptimistic organization version. يبقى الشعار الحالي ظاهرًا أثناء رفع البديل، ولا تتغير الإشارة العامة إلا داخل معاملة finalize ناجحة.
- تقبل النسخة المحلية PNG وJPEG فقط حتى 10MB، وتتحقق من magic bytes والأبعاد بحد 4096×4096 و16 مليون بكسل، وترفض توقيع EICAR وعلامات المحتوى النشط.
- القراءة العامة تعتمد slug وتعيد الملف النظيف الحالي فقط مع `Content-Type` ثابت من السجل، و`nosniff` وCSP مقيد وETag. لا تكشف storage key أو مسار نظام الملفات.

## حد الإنتاج

التخزين المحلي متاح في demo/test فقط. قبل الإنتاج يلزم object storage عام مضبوط، وفك صورة وإعادة ترميز فعليان لإزالة metadata والملفات متعددة التفسير، مع توليد أحجام مناسبة للعرض.
