# ADR-016 — منح فريق تشغيل المنصة

الحالة: مطبق محليًا لأفعال ADM-08.A03–A05.

## القرار

- أدوار المنصة تبقى منفصلة عن عضوية الجهات وقدرات الفرد. لا تمنح `PlatformAdmin` صلاحية مالية ضمنية.
- يبدأ الوصول بدعوة ذات token مخزن كـSHA-256 لمدة 48 ساعة، لبريد محدد وأدوار صريحة وتاريخ انتهاء للمنح. لا يقبلها إلا حساب نشط موثق البريد وفعّل MFA.
- كل المنح مؤقتة في هذا المسار، بحد أقصى 90 يومًا. `Auditor` لا يجمع دورًا تشغيليًا، و`FinanceOperator` لا يجمع `RiskReviewer` أو `PlatformAdmin`.
- استبدال المنح يستخدم `platformAccessVersion` وقفل المستخدم. المنح السابقة تُلغى ولا تُحذف، وتُنشأ منح جديدة مدققة.
- لا يستطيع مدير المنصة دعوة نفسه أو تعديل/إلغاء وصوله. تعديل المنح وإلغاء الوصول يسحبان جلسات الموظف فورًا.
- واجهات القراءة تعيد المستخدم والمنح وتواريخ الانتهاء فقط؛ لا تعيد token أو hash دعوة.

## حدود

- البريد محلي عبر `local-outbox` في demo/test.
- قراءة سجل التدقيق وتصديره ADM-08.A01–A02 غير منفذين في هذه الشريحة.
