# ADR-015 — مراجع التوثيق والتحقق الإضافي

الحالة: مطبق محليًا ضمن PART-02.

## القرار

- `VerificationReviewer` منحة منصة مستقلة عن عضويات الجهات ولا تمنح صلاحيات مالية. يلزم حساب نشط وTOTP مفعّل ومنحة غير ملغاة وغير منتهية لقراءة قائمة المراجعة.
- يستلم المراجع القضية ذريًا؛ لا يستطيع مراجع ثانٍ فتح تفاصيل قضية مسندة لغيره أو اتخاذ قرارها.
- القرار يتطلب تحدي MFA مدته خمس دقائق مربوطًا بهوية الإنسان والجلسة و`verification.decision` ومعرف submission ونسخة القضية. تغير النسخة أو الجلسة يلغي صلاحية التحدي، ويستهلك التحدي داخل معاملة القرار.
- يدعم Better Auth تطبيق مصادقة TOTP ورموز استرداد مشفرة. تسجيل الدخول لحساب مفعل يحذف جلسة كلمة المرور المؤقتة ولا ينشئ جلسة مصادقًا عليها حتى نجاح العامل الثاني.
- القرار append-only ويحدث القضية والجهة ذريًا. السبب العام فقط يظهر للجهة؛ هوية المراجع وبيانات التشغيل لا تدخل DTO العام.

## الحدود

لا توجد بعد واجهة PlatformAdmin لمنح موظفي المنصة أو إلغاء منحهم؛ الاختبار ينشئ fixture مباشرًا. تنزيل وثائق التوثيق للمراجع، إدارة الجلسات، WebAuthn، ومراقبة محاولات MFA التشغيلية الموسعة متبقية.
